# 생활비 계산소

생활비 계산소는 이사, 월세, 자취, 알바, 중고거래, 비상금, 데이트, 반려동물, 출산·육아 비용과 함께, 주휴수당·최저임금·4대보험료·퇴직금 등 노동/급여 관련 법정 기준값을 참고용으로 계산해볼 수 있는 정적 웹 계산기 모음입니다.

생활 속 중요한 결정을 하기 전에 대략적인 비용을 숫자로 확인하고, 결과를 차트·표·PDF 리포트로 정리할 수 있습니다.

## 서비스 목적

생활비 계산소는 큰돈이 들어가는 선택이나 급여·노동 관련 판단을 앞두고 "대략 어느 정도일지"를 먼저 확인할 수 있도록 만든 계산 도구입니다.

사용자가 직접 값을 입력하면 계산 결과를 요약 카드, 도넛 차트, 상세 표, 해석 문장으로 보여줍니다. 별도 회원가입이나 로그인 없이 바로 사용할 수 있으며, 입력한 금액 데이터는 서버에 저장하지 않습니다.

계산 결과는 견적서, 세금 신고, 시세 조회, 병원 상담을 대체하는 값이 아니라 상황을 점검하기 위한 참고용입니다.

## 제공 계산기

| 계산기 | 설명 | 상태 |
|---|---|---|
| 알바·부업 실수령 계산기 | 시급, 근무시간, 예상 공제, 교통비와 식비를 반영해 남는 금액을 추정합니다. | 운영 중 |
| 주휴수당 계산기 | 주 소정근로시간과 시급으로 주휴수당 발생 여부와 금액을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 최저임금 계산기 | 시급과 수습 여부로 최저임금 충족 여부와 부족액을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 4대보험료 계산기 | 월급으로 국민연금·건강보험·장기요양·고용보험 공제액을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 세후 월급 계산기 | 세전 월급과 부양가족 수로 세후 실수령액을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 연장·야간·휴일수당 계산기 | 시급과 연장·야간·휴일 근무시간으로 가산수당을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 연차·연차수당 계산기 | 근속연수로 발생 연차 일수와 미사용 연차수당을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 퇴직금 계산기 | 최근 3개월 임금과 근속일수로 예상 퇴직금을 계산합니다. | 골격만 생성, 내용 작성 예정 |
| 프리랜서 3.3% 환급 계산기 | 프리랜서 수입과 업종으로 종합소득세 환급 가능성을 판단합니다. | 골격만 생성, 내용 작성 예정 |

이사·월세·자취·중고거래·비상금·데이트·반려동물·출산육아 계산기 8종은 `pages/_archive/`로 보관 이동했습니다. 완전 삭제 예정이며 현재는 사이트에 노출되지 않습니다.

노동/급여 계산기 9종은 `assets/js/labor-calc.js` 하나의 계산 모듈을 공유하며, 기준값은 `assets/data/rates.json`과 `assets/data/tax_table.json`에서 읽어옵니다.

## 주요 기능

- 입력값 기반 즉시 계산
- 결과 요약 카드
- 항목별 도넛 차트
- 상세 표
- 한눈에 해석하기 문장
- 결과 복사
- CSV 다운로드
- PDF 저장용 전용 리포트 출력
- 모바일 반응형 화면
- 개인정보 및 입력값 서버 저장 없음

## 화면 구성

- 메인 허브 페이지: 계산기 목록으로 이동할 수 있는 첫 화면
- 계산기 상세 페이지: 입력폼, 결과 요약, 차트, 상세 표, 해석 문장 제공
- 결과 리포트 PDF: 입력폼과 광고 영역을 제외한 계산 결과 중심의 출력 화면
- 안내 페이지: 소개, 가이드, FAQ, 문의, 이용 안내, 개인정보처리방침
- `pages/guide/`: 노동/급여 계산기용 설명 글이 들어갈 자리 (현재 비어 있음)

## 개인정보 및 데이터 처리

생활비 계산소는 회원가입과 로그인을 제공하지 않습니다.

계산기에 입력한 금액 데이터는 서버로 전송하거나 저장하지 않으며, 모든 계산은 사용자의 브라우저에서 처리됩니다. PDF 저장과 CSV 다운로드 역시 사용자의 브라우저에서 생성됩니다.

계산 결과는 참고용입니다. 실제 비용, 견적, 세금, 시세, 병원비 등은 개인 상황과 조건에 따라 달라질 수 있습니다.

## 기술 구성

- 정적 HTML/CSS/JavaScript
- 서버 없음
- DB 없음
- 외부 API 없음
- Cloudflare Pages 배포 가능
- `window.print()` 기반 PDF 저장
- 브라우저 기반 CSV 생성

## 갱신 절차

노동/급여 계산기 9종은 계산 로직과 기준값이 분리되어 있어, **매년 1월에 `assets/data/rates.json` 파일만 고치면 계산기 전체가 갱신됩니다.** 최저임금, 4대보험 요율, 연차·퇴직금 관련 법정 기준이 모두 이 파일 안에 있습니다.

요율을 변경한 뒤에는 반드시 회귀 테스트를 실행해 계산 결과가 의도대로 바뀌었는지 확인하세요.

```bash
node tools/labor-calc.test.js
```

테스트가 실패하면, 요율 개정이 원인인 실패인지(기대값을 함께 갱신) 계산 로직 문제인지(원인을 찾아 수정) 구분해서 처리합니다.

근로소득세 간이세액표가 개정되면 `tools/convert_tax_table.py`로 `assets/data/tax_table.json`을 다시 생성합니다.

```bash
pip install xlrd --break-system-packages
python tools/convert_tax_table.py 근로소득_간이세액표_조견표_.xls
```

계산기 페이지를 추가·삭제하거나 `pages/` 구조가 바뀌면 사이트맵을 다시 생성합니다. `pages/_archive/`는 자동으로 제외됩니다.

```bash
python tools/build_sitemap.py
```

## 로컬 실행 방법

1. 저장소를 다운로드합니다.
2. `index.html`을 브라우저로 엽니다.
3. 또는 VS Code Live Server를 사용합니다.

노동/급여 계산기는 `assets/js/labor-calc.js`가 `/assets/data/`에서 절대경로로 JSON을 불러오므로, `file://`로 직접 열면 데이터 로딩이 실패합니다. 반드시 정적 파일 서버로 확인하세요.

```bash
python -m http.server 8000
```

## 배포 방법

Cloudflare Pages에 정적 사이트로 배포할 수 있습니다.

```text
Framework preset: None
Build command: 비움
Build output directory: .
```

GitHub 저장소와 연결하거나 Cloudflare Pages의 Direct Upload로 프로젝트 루트 폴더를 업로드하면 됩니다.

## 검색 엔진 등록 안내

현재 배포 주소는 아래와 같습니다.

```text
https://costcheck.kr/
```

Google Search Console 등록 순서:

1. Google Search Console에 접속합니다.
2. URL 접두어 방식으로 `https://costcheck.kr/`을 등록합니다.
3. 안내에 따라 소유권을 확인합니다.
4. `Sitemaps` 메뉴에서 `https://costcheck.kr/sitemap.xml`을 제출합니다.
5. 주요 계산기 URL이 색인 가능한지 URL 검사로 확인합니다.

네이버 서치어드바이저 등록 순서:

1. 네이버 서치어드바이저에 접속합니다.
2. 사이트 관리에서 `https://costcheck.kr/`을 추가합니다.
3. 안내에 따라 사이트 소유권을 확인합니다.
4. 사이트맵에 `https://costcheck.kr/sitemap.xml`을 제출합니다.
5. 웹 페이지 수집 요청에서 주요 계산기 URL을 확인합니다.

**주의:** `part-time-income-calculator.html`의 URL은 검색 순위가 쌓여 있어 경로를 변경하지 않습니다.
